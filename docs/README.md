# docs

The project README describes the product. These pages are what a user or a maintainer reads.

## Using Leela

- [guide.md](guide.md): starting Leela, each part of the app, lessons, the keys, and what it costs to run.
- [present.md](present.md): present a notebook as slides. Keys, the audience window, live runs, what the room can see, and recovery.
- [search.md](search.md): the code search dialog, its modes, its keys, and what it records.

## Maintaining Leela

- [develop.md](develop.md): get the code, the code layout, blocks, the desktop builds, a release, and the tests.
- [decisions.md](decisions.md): the decisions the code follows, with the reason and the place in the code. Read the entry before you change that code.
- [integration.md](integration.md): the agent host, its capability groups and the block behind each, and the model providers.
- [desktop.md](desktop.md): the packaged app. Processes, the browser, folder selection, and the macOS menu bar.

`media/` holds the README's pictures. `screenshots/` holds the pictures the guide and the search page use.
