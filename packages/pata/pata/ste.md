Write the sentences in ASD-STE100 simplified technical English.

- Put one idea in one sentence. Then stop.
- Keep each sentence to 20 words or fewer.
- Use the present tense and the active voice. Name the doer.
- Use one word for one meaning, every time. Never vary a term for texture.
- Use the plainest word that is still correct.
- Write the article: "the reader reads the file", not "reader reads file".
- Do not use an em dash, a semicolon, or a parenthetical aside.
- Do not write a list. Write sentences.
